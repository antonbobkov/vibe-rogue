# DECISIONS

Ambiguity log (`40-implementation-plan.md` § PLN-07.1). One row per decision taken where a rule was
missing, ambiguous, or self-contradictory. Rows are append-only; IDs are never reused or renumbered.

| ID | Spec IDs | Question | Decision | Why | Milestone |
|---|---|---|---|---|---|
| D-001 | PLN-02 R2, TEC-02 | R2 exempts "the storage adapter in `save.js`", not the whole file. How does `dom-free.test.js` express a partial exemption? | `src/save.js` is scanned like any other core module, but the single identifier `localStorage` is permitted in it. `src/render.js`, `src/main.js` and `src/screens/*` stay fully exempt. | Keeps R2 enforced over the rest of `save.js` (serialize/deserialize must stay headless) while allowing exactly the adapter TEC-09 requires. | M00 |
| D-002 | PLN-02 R2, R3 | Should the R2/R3 scanners match forbidden text inside comments and string literals? | No. Both scanners strip comments and string bodies before matching; `${...}` interpolations inside template literals are kept, because they are code. | Item and script data (`data/*.js`, `SCR-10` templates) contain English prose that would otherwise trip on words like `function`, `class` or `window`, producing false failures that R10 forbids fixing by renaming spec content. | M00 |
| D-003 | PLN-04, PLN-06 M00 | `npm test` must run the unit, integration and meta tiers but not the Playwright specs. `node --test test/` cannot express that. | `npm test` runs `node tools/dod.js --node`, which discovers `test/**/*.test.js` itself and passes the explicit file list to `node --test`. | `node --test <dir>` treats *every* `.js` file under a directory named `test` as a test file, so it would try to execute `test/e2e/*.spec.js` and `test/fixtures/*.js`. Positional glob patterns need Node ≥ 22, but PLN-04 fixes CI at Node 20. | M00 |
| D-004 | PLN-04 | PLN-04 describes the DoD as "`node --test` filtered by milestone tag, then the meta tests". Are the meta tests included in the filtered run as well? | No. Step 1 runs `test/**/*.test.js` outside `test/meta/` with `--test-name-pattern`; step 2 runs `test/meta/*.test.js` with no filter. | The repo rules (R2, R3, R5, ACC coverage) always apply in full, and splitting the two steps avoids running the meta tier twice per DoD. | M00 |
| D-005 | PLN-02 R4, PLN-07.4 | R4 requires an exact `@playwright/test` pin but names no version. | Pinned `1.63.0`. | Latest stable at scaffold time; every `playwright < 1.55.1` carries a published advisory (GHSA-7mvr-c777-76hp), so the pin also keeps `npm audit` clean. PLN-07.4's downgrade path was not needed — the Chromium download succeeded. | M00 |
